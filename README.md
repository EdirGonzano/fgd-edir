# FGD-Edir

Mi plataforma de estudio de **Fundamentos de Gestión de Datos**: lecciones con diagramas interactivos, fichas rápidas de cada comando, laboratorio SQL en el navegador, repaso espaciado y simulacros.

Hecha por Edir. Todos los datos son ficticios.

## Usar
Abrir la web publicada (GitHub Pages) o, en local: `python -m http.server 8791` y entrar a http://127.0.0.1:8791

## Datos para Google Colab
La carpeta [`datos/`](datos/) tiene los CSV y las bases `.db`. En la web, la sección «Puente a Colab» trae las celdas listas para pegar.
